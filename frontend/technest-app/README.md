# 🛍 TechNest Frontend – React + Vite

Đây là mã nguồn Frontend của hệ thống thương mại điện tử **TechNest**, được xây dựng bằng **React + Vite**.

Frontend bao gồm:

- Trang người dùng (User)
- Trang quản trị (Admin)
- Giỏ hàng
- Đặt hàng
- Dashboard thống kê

---

## 🚀 1. Công nghệ sử dụng

- React 18
- React Router DOM
- Vite
- Context API (Auth, Cart)
- CSS + Inline Styles

---

## 📦 2. Cách cài đặt & chạy

### ✔ Bước 1 — Mở thư mục frontend

cd frontend/technest-app

### ✔ Bước 2 — Cài đặt dependency

npm install

### ✔ Bước 3 — Chạy frontend

npm run dev

Frontend chạy tại:
👉 http://localhost:5173

---

## 🔗 3. Kết nối với Backend

Frontend tự động gọi API backend tại:
http://localhost:8080

(được cấu hình trong `api.js`)
